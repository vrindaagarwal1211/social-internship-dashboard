# Governance Sentiment Analysis Dashboard

This project analyzes citizen perceptions of two flagship Government of India initiatives:

- Digital India
- Ayushman Bharat (PM-JAY)

## Features

- Interactive Streamlit dashboard
- Demographic analysis
- Digital India analysis
- Ayushman Bharat analysis
- Comparative insights
- Recommendations

## Technologies

- Python
- Streamlit
- Plotly
- Pandas
